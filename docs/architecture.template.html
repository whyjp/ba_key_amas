Blue Archive add-on: architecture

A resident Windows program in Rust that reads the game screen and answers with a card and icons. Source of truth: docs/ARCHITECTURE.md and docs/adr/.

1. Runtime flow

The loop polls slowly in a battle and when a view is read and still; the overlay thread wakes on change.

4. OCR pipeline

Runs on CPU or DirectML (--features directml, 2.7 times faster on the fixtures, identical text). See ADR 0002.

6. Input policy

  • Passive code gets a read-only handle. Input exists only on Exclusive, taken when the player starts a scan.
  • Guards at one boundary: point on a monitor, window layout unchanged, target window under the point, partial input is effect_unknown and never retried.
  • Every input call is logged without content; the player's own input is blocked during the scan, hardware ESC returns control.
