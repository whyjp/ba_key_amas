# 결정 기록

결정마다 파일 하나를 둔다. 각 파일은 배경, 결정, 기각한 대안, 결과, 근거, 다시 볼 조건을 적는다. 상태는 확정,
대체됨, 보류(브랜치에 구현했지만 병합하지 않음) 중 하나다.

| # | 결정 | 상태 |
|---|---|---|
| [0001](0001-addon-shell.md) | 상주 애드온, 수동 관찰 우선, 스캔은 직접 시작 | 확정 |
| [0002](0002-ocr-stack.md) | 프로세스 내 ONNX Runtime의 PP-OCR, DirectML은 선택, 이름은 닫힌 집합 읽기 | 확정 |
| [0003](0003-native-desktop-control.md) | HCU 헬퍼 대신 Win32로 프로세스 내 데스크톱 제어 | 확정 |
| [0004](0004-input-policy.md) | 입력은 스캔에만, 한 경계에서 안전장치로 막고, 관찰만 하고 가로채지 않음 | 확정 |
| [0005](0005-static-db-dynamic-screen.md) | 정보는 정적 DB에서, 화면은 조회 키만 제공 | 확정 |
| [0006](0006-enemy-weighting.md) | 적 방어 타입과 공격 타입 비중을 HP로 가중 | 확정 |
| [0007](0007-overlay-windows.md) | 레이어드 클릭 통과 창, 변경 캐시, 북마크 카드 | 확정 |
| [0008](0008-raid-modelling.md) | 레이드를 시즌별 난이도 행으로 모델링하고 화면으로 인식 | 확정 |
| [0009](0009-build-limits.md) | RAM과 디스크를 제한하는 빌드 설정 | 확정 |

템플릿: 배경, 결정, 대안, 결과, 근거, 다시 볼 조건.
